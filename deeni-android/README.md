# ديني — تطبيق Android

تطبيق إسلامي عربي بواجهة من اليمين إلى اليسار، يعمل على Android 6.0 فأحدث، ويستهدف Android 15. اسم الحزمة: `com.deeni.app`. الإصدار الحالي في المشروع: `1.0.2`.

## الأقسام الموجودة حاليًا

- المصحف: صفحات 1–604 عبر ملفات SVG لمصحف حفص، مع حفظ الصفحة، تكبير العرض، تحديد الآية، والتنقل بين الصفحات.
- مكتبة القراء: تحميل قائمة القراء والتلاوات المتاحة من خدمة MP3 Quran، وتشغيل السورة عند توفرها.
- توقيت الآيات: قراءة بيانات التوقيت عند توفرها، مع تكرار الآية الحالية وتغيير سرعة التشغيل.
- البحث في القرآن والتفسير الميسر عبر خدمة AlQuran Cloud.
- الأذكار والأدعية، التسبيح، الحفظ والمراجعة اليومية، الملاحظات، الآيات المحفوظة، السيرة، مختارات الحديث، قصص الأنبياء والصحابة، التجويد، مبادئ الفقه، أسماء الله الحسنى، المسابقات.
- مواقيت الصلاة حسب المدينة والدولة، واتجاه القبلة باستخدام إحداثيات المدينة وحساس اتجاه الهاتف مع تصحيح الانحراف المغناطيسي إلى الشمال الحقيقي.
- زر لإعادة تحميل صفحة المصحف عند تعثر تحميل ملف الصفحة الخارجي.
- الوضع الفاتح والداكن، وحفظ بعض التفضيلات محليًا.

## تنبيهات مهمة حول الدقة والاكتمال

- المصحف يعرض صفحات SVG خارجية من مشروع ملفات مصحف حفص، وليس صورًا مضمّنة داخل التطبيق؛ لذلك يحتاج اتصالًا بالإنترنت. يجب مراجعة مصدر ملفات الصفحات قبل الاعتماد عليها في النشر.
- التسميع الصوتي الحالي يعتمد على خدمة التعرف الصوتي العامة في Android ويعرض النص الذي التقطه الهاتف. **لا يكتشف أخطاء التلاوة القرآنية بدقة، ولا يصحح التجويد أو المخارج، ولا يُعد بديلًا عن معلّم متقن.**
- مزامنة التلاوة مع الآيات تعتمد على بيانات التوقيت المتاحة للقارئ والسورة؛ لا تتوفر لجميع التلاوات.
- المكتبات الدينية الحالية مختارات تأسيسية وليست موسوعة شاملة. لا تُعرض أعداد كبيرة بادعاء الاكتمال، ويجب مراجعة النصوص والمراجع الشرعية قبل النشر العام.
- أوقات الصلاة تعتمد على اسم المدينة والدولة وطريقة الحساب التي يختارها المستخدم؛ تتوفر طرق حساب شائعة، وينبغي مطابقتها مع تقويم الجهة الرسمية في منطقته.
- تم بناء Debug APK بنجاح عبر GitHub Actions للالتزام `658f2a3397b1bb9e76f2c27e1e37db477f18e19c`، لكن لم يُختبر التطبيق فعليًا على هاتف Infinix X6725؛ نجاح البناء لا يثبت خلو التشغيل من الأخطاء.

## البناء

يُبنى ملف Debug APK عبر GitHub Actions باستخدام JDK 17 وGradle 8.9. ناتج البناء:

`app/build/outputs/apk/debug/app-debug.apk`

الأتمتة تعمل عند تحديث ملفات `deeni-android/**` أو عند تشغيل workflow يدويًا. ملف Debug مخصص للتجربة، وليس إصدارًا موقّعًا للنشر على المتجر.
