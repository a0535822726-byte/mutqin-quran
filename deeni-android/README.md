# ديني — مشروع Android

مشروع أندرويد مستقل باسم ديني، موجّه للأجهزة التي تعمل بنظام Android 6.0 فأحدث، مع استهداف Android 15.

## البناء

يُبنى ملف Debug APK عبر GitHub Actions باستخدام JDK 17 وGradle 8.9. ناتج البناء المتوقع: `app/build/outputs/apk/debug/app-debug.apk`.

## الحالة الحالية

هذه مرحلة تأسيسية للتحقق من سلسلة البناء وواجهة عربية أولية. أقسام التسميع الصوتي، المصحف الكامل، المحتوى الموثق، والمزامنة ليست منفذة بعد، ولا ينبغي اعتبارها ميزات جاهزة.
